# 💸 Subscription Leak Detector & Optimizer

A lightweight CLI tool built in Python to help track monthly subscriptions, figure out cost-per-use, and rank what you should probably cancel first before your wallet cries.

I built this for a class project because tracking recurring payments manually is annoying and money leaks add up fast.

---

## ✨ Features
* **Add Subscriptions:** Log subscription names, monthly costs, and how often you actually use them.
* **Smart Priority Ranking:** Automatically calculates cost-per-session and ranks subscriptions from highest waste (cancel priority) to best value.
* **Zero-Crash Guardrails:** Built with error handling so invalid inputs or zero usage won't crash the app.
* **Terminal Menu Loop:** Simple 1-2-3 interactive menu interface.
